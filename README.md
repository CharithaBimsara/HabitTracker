# Habit Tracker Frontend

A simple React app to interact with the Habit Tracker API.

![Demo Screenshot](demo.png)

## 🛠 Tech Stack

- React (with JSX)
- Vite
- Axios (for API calls)
- Tailwind CSS (optional styling)

## 📦 Features

- Add a habit
- View all habits
- Mark habit as completed
- Display current streaks

## 🚀 How to Run

```bash
npm install
npm run dev
